## Uso del Formato

Este formato es referencial y puede utilizarse para solicitudes de alta, modificación o baja de accesos.

El contenido mínimo podrá registrarse en este documento, en Mesa de Servicios, Jira, correo institucional, comentario estructurado o registro equivalente. No será necesario adjuntar este formato si el ticket contiene los datos mínimos, aprobaciones y evidencias correspondientes.

Este formato no reemplaza el ticket o registro principal, la validación de vínculo laboral o contractual, la implementación técnica ni el cierre de la atención.

## Ejemplo Orientador

Para una solicitud simple de alta de usuario, el ticket puede reemplazar este formato si contiene datos del usuario, accesos requeridos, justificación, aprobación del área responsable y evidencia de implementación.
