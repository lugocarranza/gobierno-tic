## Uso del Formato

Este formato es referencial y puede utilizarse para documentar la especificación funcional de requerimientos, mejoras significativas o cambios funcionales relevantes.

El contenido mínimo podrá registrarse en este documento, en un adjunto, en Jira, Mesa de Servicios, correo institucional, comentario estructurado o registro equivalente. Para requerimientos simples o cambios menores, no será necesario elaborar un documento separado si el ticket contiene la información suficiente.

Cuando el requerimiento se formalice mediante este formato, deberá conservar la conformidad del área usuaria. En registros equivalentes, la conformidad podrá constar mediante aprobación en Jira, correo, comentario autorizado o medio similar, salvo que se requiera firma expresa para el caso.

Este formato no reemplaza el ticket o registro principal, el Formato de Cambio cuando corresponda, la aprobación del cambio ni la autorización del pase a producción.

## Ejemplo Orientador

Este formato puede reemplazarse por una historia de usuario o ticket de Jira si contiene, como mínimo, la necesidad, alcance, criterios de aceptación, responsable, fecha y conformidad o validación cuando corresponda. Si se requiere formalización documental del requerimiento, deberá conservarse la firma del área usuaria o una aprobación equivalente autorizada.
